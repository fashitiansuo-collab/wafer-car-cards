# ウエハース車カード — 設計書

日付: 2026-10-10
状態: 設計承認済み、仕様書レビュー待ち

## 1. 目的と前提

- **何か**: ウエハースの袋を破り、かじって食べると、ウィキメディア・コモンズの車の写真を使ったカードが 1 枚出る。集めて図鑑を埋める。
- **誰のため**: 作者本人の **CSS 表現の習作・作品**。ゲームの経済要素より、ホロカードと開封演出の作り込みを優先する。
- **成功の条件**
  - 5 段階のレアそれぞれで、カードの加工(写真の扱い + ホロ)がはっきり違って見え、傾けると気持ちよく光る。
  - 袋を破る → かじる → めくる、が指でもマウスでも自然に操作できる。
  - UI が「縦型の GT SPORT 風」(額縁の文法)として破綻していない。
  - 写真のクレジットとライセンス表示が欠けていない。
- **ラインナップは作者に伏せる**。カードの中身(車種・写真)は実装者が選び、本書には書かない。`src/data/cards.json` を開くとネタバレになる。

## 2. 技術方針

- **Svelte 5 + Vite**、TypeScript。`vite build` の静的出力をブラウザで開くだけで動く(サーバー不要)。
- カードは poke-holo(simeydotme/pokemon-cards-css)と同じ方式: 位置と傾きを CSS 変数に流し、見た目は CSS のレイヤーで描く。
- UI は `gt-showroom-ui` スキルの **SPORT 系統**。トークン(`tokens.css` / `type.css`)をそのまま写し、部品(Header / GuideBar / Brackets / TitleLockup / BottomStrip)を縦向けに移植する。
- 書体は Barlow / Barlow Condensed / Noto Sans JP / JetBrains Mono を同梱する(実行時に Google Fonts へ接続しない)。アイコンは Phosphor Light / Regular。
- 名称・ロゴ・画像・音に Gran Turismo / Polyphony / Sony の素材、実在の菓子ブランドを入れない。借りるのは文法だけ。

## 3. 画面構成(縦型 SPORT)

### 骨格

```
┌─┬──────────────────────┬───────────┐
│▣│ 開封  ガレージ  記録  │ 07/10 0:42│ ヘッダー(モジュール高 = ロゴ枠の幅)
├─┴──────────────────────┴───────────┤
│                                     │
│         [ 袋 / カード ]              │ 中央 = 被写体だけ。UI を重ねない
│                                     │
│ MAKER                               │ 結果画面のみ: Title lockup
│ MODEL NAME                1998 · R  │ (カードの下の帯に置く)
├──────────────────┬──────────────────┤
│ 図鑑 23/45       │ 直近 R ×1        │ ボトム帯 2 セル(進捗はセル下端 2px)
│ ━━━━━━━━━━━──── │ UR ×0 SEC ×0     │
├──────────────────┴──────────────────┤
│ ⇆ 上端をなぞって破る   ⏎ かじる     │ ガイドバー(次の操作だけ)
└─────────────────────────────────────┘
```

- 左レールは使わない(縦画面では機能をヘッダーのタブへ)。ボトム帯は 4 セルから 2 セルへ。
- ヘッダー右のステータスは常に「ストック数 / 次の補充までの残り時間」。数字は Barlow tabular(7 セグは使わない)。満タン時は `FULL`。
- PC では 9:19.5 の縦長の画面を中央に置き、左右は `--ink-0`。
- 比例縮尺: 基準 390×844。`html { font-size }` を画面幅と高さの小さいほうに比例させる。

### 画面

1. **開封(ホーム)** — 中央に袋。ストック 0 なら袋を暗くし、ガイドバーに「次の袋まで 0:42」。
2. **開封シーケンス** — ヘッダーは残し、ボトム帯は暗く退く。
3. **結果** — カード(傾けられる)+ Title lockup + 「もう一袋」「ガレージへ」。新規は `NEW`、ダブりは `×n` のタグ。
4. **ガレージ(図鑑)** — 3 列グリッド。上にレア別の絞り込みタブ(ALL / C / UC / R / UR / SEC)。未入手は番号と「???」のシルエット。フォーカスは四隅の角括弧(拡大しない)。
5. **カード詳細** — 大きく傾けられる。タップで裏返すとクレジット(作者・ライセンス・元ページ)と車の情報(年式・国)。
6. **記録** — 食べた数、レア別の所持数、全クレジット一覧、デバッグスイッチ(レア確定)。

### 色

モノクロが基本。色はレアの印(小さな縦線・タグ)だけに使う。

| C | UC | R | UR | SEC |
|---|---|---|---|---|
| 灰 `--paper-2` | 緑 `#6fbf1a` | 青 `#2e5dd3` | マゼンタ `#d01e94` | 金(黄 `#e0b400`) |

SPORT の禁止事項(角丸、影、UI のグラデーションとグロー、ぼかしのダイアログ、700 の本文、ツールチップ、タイルの拡大、バウンス)は **UI に** 適用する。カードは被写体なので、ホロ・グラデーション・光は自由に使う。

## 4. カードとレア別の加工

### 共通の仕組み

- レイヤー: `写真` → `shine`(ホロ)→ `glare`(反射)→ `枠と文字`。
- 入力(マウス位置 / 指ドラッグ / `deviceorientation`)を次の CSS 変数に流す: `--pointer-x` `--pointer-y` `--pointer-from-center` `--pointer-from-left` `--pointer-from-top` `--background-x` `--background-y` `--rotate-x` `--rotate-y` `--card-opacity`。
- 傾きはバネ(stiffness / damping)で追従し、離すと中央へ戻る。iOS のジャイロは許可のタップを挟む。
- **写真の輝度マスク**: `mask-image: url(写真)` + `mask-mode: luminance` で、ホロを写真の明るい部分(クローム、ボディのハイライト)だけに効かせる。poke-holo の箔マスク画像の代わり。
- きらめきは生成したノイズ PNG 1 枚を `background-blend-mode` で使い回す。
- 形: 63:88。C〜R は枠付き(上: メーカー小 + 車名、写真窓 4:3、下: 年式・国、番号 `023/045`、レアの印)。UR / SEC はフルアート(全面写真、文字は下端の黒帯)。

### レア別

| レア | 写真の格 | 写真の加工 | ホロ(poke-holo の参考元) |
|---|---|---|---|
| C | 駐車場の日常スナップ | 枠付き、紙のノイズ、彩度を少し落とす | なし。白い反射がうっすら流れるマット |
| UC | きれいに撮れた普通の写真 | 枠付き、そのまま | リバースホロ: 写真窓の外(枠)だけ細かい縦のきらめき |
| R | 走行中・イベントの良い写真 | 枠付き、銀の枠 | レギュラーホロ: 写真窓に虹の縦帯。枠は金属の反射 |
| UR | 劇的な光・構図の写真 | フルアート、コントラスト強め | レインボー(V 系フルアート): 斜めの虹線 + きらめき、輝度マスクで明部が強く光る |
| SEC | 伝説級・特別な一瞬 | フルアート、金の縁、車名は浮き彫り風 | シークレットゴールド + コスモス: 全体に金の箔、暗部に銀河の模様、傾きで金と虹が入れ替わる |

- 同じ車種が低レアと高レアの両方に出てよい(写真は別)。
- `prefers-reduced-motion`: バネと自動の揺れを止め、触った位置への直接の反応だけ残す。

## 5. 開封演出

### 袋

架空の銀の袋。アルミ箔のしわを `conic-gradient` とノイズで描き、カードと同じ入力で光が動く。文字は Barlow Condensed で `WAFER / CAR CARD COLLECTION` と `No.` を積み、ロゴ枠に架空のマーク。

### 流れ

1. **袋** — ガイド: `⇆ 上端をなぞって破る`。
2. **破る** — 上端の切り口から横ドラッグ。破れ目はギザギザの `clip-path` で指を追う。70% を超えると切れ端が回転しながら落ちる。途中で離すとその位置で止まる(続きから再開できる)。Enter で自動的に破る。
3. **中身** — 袋が下へ抜け、ウエハース(格子の焼き目 `repeating-linear-gradient` + クリームの層の断面)が出る。カードは裏向きでウエハースの後ろ。ガイド: `⏎ タップしてかじる`。
4. **かじる** — タップ位置が歯形付きの半円で欠ける(`mask` に円を重ねる)。かけらが数粒落ちる。4〜6 口で食べ終わる。かじった穴からカードの裏が見えてくる。Enter / Space でも 1 口。
5. **めくる** — レア別(下表)。
6. **結果** — カードが中央に収まり、Title lockup がボトム帯から 12px 上がってフェードイン。

| レア | めくり方 |
|---|---|
| C / UC | 0.5 秒でそのまま返る |
| R | 返る瞬間に光が 1 回横切る |
| UR | ボトム帯とガイドが暗く退き、ゆっくり返り、虹が横切る |
| SEC | 画面がほぼ黒になり、金の縁だけ先に見えてから返る。ヘッダー右に `SECRET` タグ |

- **予兆**: UR / SEC のとき 50% の確率で、こぼれるかけらが 1 粒だけきらめく。外れのときには出ない。
- **スキップ**: ガイドバーの `» スキップ` で結果まで飛ぶ。めくる演出だけは残す。
- 音は入れない(後で足せるよう、演出の節目をイベントとして出しておく)。
- UI の動きは `cubic-bezier(.2,0,0,1)`、120〜240ms、バウンスなし。被写体(切れ端・かけら・カード)だけ物理的に動く。

## 6. データと保存

### カード一覧 `src/data/cards.json`

```ts
type Rarity = 'C' | 'UC' | 'R' | 'UR' | 'SEC';
interface Card {
  id: string;            // 'c023'
  no: number;            // 23
  rarity: Rarity;
  maker: string;
  model: string;
  year: number;
  country: string;
  image: string;         // '/cards/c023.jpg'
  focus?: string;        // object-position, 例 '50% 60%'
  credit: {
    author: string;      // HTML を除いた文字
    license: string;     // 'CC BY-SA 4.0'
    licenseUrl: string;
    sourceUrl: string;   // コモンズのファイルページ
    modified: boolean;   // 加工した場合 true(「改変あり」と表示)
  };
}
```

第一弾は 45 枚前後(C 15 / UC 12 / R 9 / UR 6 / SEC 3)。

### 写真の取得 `scripts/fetch-commons.mjs`

- 入力: コモンズのファイル名と、カードの属性(レア・車名など)の一覧。
- 処理: Commons API の `prop=imageinfo&iiprop=url|extmetadata&iiurlwidth=900` で縮小版の URL とメタデータを取り、`public/cards/` に保存し、`cards.json` のクレジットを埋める。`CREDITS.md` も出力する。
- User-Agent に連絡先付きのツール名を入れる(Wikimedia の User-Agent 方針)。
- ライセンスは CC0 / PD / CC BY / CC BY-SA だけ受け付け、それ以外は止めて報告する。
- 選定の基準: §4 の写真の格。ナンバープレートが読める写真、人の顔がはっきり写った写真は避ける。

### クレジット表示

カード裏面、記録画面の一覧、`CREDITS.md` の 3 か所。CC BY-SA の写真は加工しているので「改変あり」と書く。

### 補充タイマー

- 状態: `stock`(0〜10)、`lastRefillAt`(ms)。
- 計算: `n = floor((now − lastRefillAt) / 60000)`。`stock = min(10, stock + n)`、`lastRefillAt += n × 60000`。満タンになったら `lastRefillAt = now`。
- 初回は満タン(10)。タブを閉じていても時刻の差で補充される。
- 1 袋開けるとき、満タンからなら `lastRefillAt = now` にしてタイマーを始める。

### 保存

- `localStorage` のキー `wafer-cards:v1`:
  ```ts
  interface Save {
    v: 1;
    stock: number;
    lastRefillAt: number;
    eaten: number;
    owned: Record<string, number>;   // カード id → 枚数
    firstPulledAt: Record<string, number>;
  }
  ```
- 読み書きは try/catch で囲む。壊れたデータや未知の `v` は初期状態にする。保存できない環境ではメモリだけで遊べる。

### 抽選

- レアを重み付きで選ぶ(C 55 / UC 25 / R 13 / UR 6 / SEC 1)→ そのレア内で均等に 1 枚。
- 乱数関数を引数で受け取り、テストではシード付きにする。
- デバッグスイッチでレアを固定できる。

## 8. テストと確認

- **Vitest**: `refill`(境界: 59.9 秒、ちょうど 60 秒、満タン、長時間不在)、`draw`(シード付きで分布が重みに近い、デバッグ固定)、`save`(壊れた JSON、未知の版、保存不可)。
- **見た目**: `?debug` で 5 レアを並べる確認画面。390×844 と PC 幅でスクリーンショットを撮り、SPORT の禁止事項チェックリストと照らす。カードは複数の傾きで撮る。
- **操作**: 破る(途中で離す/最後まで)、かじる(4〜6 口)、スキップ、キーボードだけで一周、ジャイロ許可の流れ。
