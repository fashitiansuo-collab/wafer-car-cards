# PR-01 ウインクするロードスター

- **種類**: プロモーションカード(合言葉で受け取る。図鑑の集計には入らない)
- **車種**: マツダ MX-5(初代 NA、写真は 1991 年式の北米仕様 Miata)
- **理由**: 「ウエハースのおまけ」の顔には強さより親しみ。世界で一番売れた 2 人乗りオープンで、誰が見ても笑顔に見える。リトラクタブルライトが「めくる・開く」演出と相性がよい。AE86 と 2000GT は SEC 本番に取っておく。

## リサーチ(2026-10-11)

- Awwwards: 自動車カテゴリの一覧は読めたが、サムネイルが読み込まれず作品は確認できなかった。
- CodePen: 検索はログインが必要で見られなかった。
- CSS Design Awards: 今回は見ていない。
- Behance(「car poster typography」): 下の手法を拾った。

| 手法 | 傾向 | 今回の使い方 |
|---|---|---|
| 巨大な文字を車の後ろに | 細長い書体の車名を画面いっぱいに置き、手前に車 | 赤い「MX-5」を切り抜いた車の後ろに。傾けると文字と車が違う量だけ動いて奥行きが出る |
| 縦書きの日本語の柱 | 異名や車名を縦に組み、横組みの英字と対比させる | 「人馬一体」 |
| 単色+網点 | 赤一色、網点、粗い質感 | 赤い網点を車の下に置き、上下を薄くする |
| 小さな仕様 | 隅に等幅の小さな文字で仕様を並べる | 寸法・車重・エンジン、撮影データ |

## コンセプト

「ウインクするロードスター」。紙のポスターのような明るいカード(暗い UI の中で目立たせる)。キーワード: 軽さ / 笑顔 / 1989。

## 写真

- File:1991 Mazda MX-5 Miata in Classic Red, Front Right, 07-15-2022.jpg
- 作者 Elise240SX、CC BY-SA 4.0、切り抜き(rembg u2net)と縮小をしたので改変あり
- 撮影データ: Canon PowerShot G10, 16mm F3.5 1/200s ISO200, 2022/07/15

## 実装

- `src/cards/special/PromoPR01.svelte`、切り抜きは `public/promo/pr01-car.webp`(1400px, 178KB)
- ライトの位置は切り抜き画像の中の % で `promos.json` の `lights` に記録(左 53.7/46.2、右 90.8/43.0)
- 固有の動き: めくった直後に両方のライトが点き、左だけ 2 回まばたき(1.6 秒)。以後は傾けるほど光が強くなる
- 赤い車が赤い文字に埋もれないよう、切り抜きに細い白い縁(drop-shadow)を付けた

## 確認

- 390×844 と大きな表示で配置・光を確認。車が下の文字に重なっていたので上へ 7cqw 動かし、網点を文字の下から外した
- ライトの光が `screen` 合成では白いレンズの上で見えなかったので、大きくして `plus-lighter` に変えた
- 合言葉はアプリに SHA-256 のハッシュだけを持つ。URL の `?promo=` は読んだらアドレスバーから消す
- `prefers-reduced-motion` ではウインクを止める

## 次に活かすこと

- 傾きの計算は単位のない `--pointer-from-*` で書く(角度を deg で割る計算は Safari で効かないため)
- 切り抜きは rembg で十分な精度が出た。ガラス越しの背景は残るが、ガラスなので自然
- リサーチは Behance が見やすい。Awwwards と CodePen はログインや遅延読み込みの壁があるので、作者に参照作品の URL をもらうのが早い
