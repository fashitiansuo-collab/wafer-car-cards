# 第3弾(抹茶):ホモロゲ&レース

2026-10-15。テーマは作者が選んだ「ホモロゲ&レース」。市販のホモロゲーションモデルと、そのレース仕様・競技車。

## 新要素

- **抹茶ウエハース**: 第1弾と同じ写真(Paolo Neo、パブリックドメイン)から色を付け替え、緑のクリーム 1 層(`scripts/make-wafer.py`)。色は Commons の抹茶ウエハースの写真(CC0)を見て決めた。
- **スペック**: エンジン・出力・重量。英語版 Wikipedia の infobox から取得し(`scripts/fetch-specs.py`)、**その仕様の値かどうかを手で確かめた**ものだけ残した。車種全体の値やレース仕様と違う値は消した(不明ならなし)。カード裏面に載せ、出典(Wikipedia, CC BY-SA 4.0)も書く。
- **解説文**: 日本語版 Wikipedia の冒頭から 90 字以内(無ければ英語版)。カード裏面に引用として載せ、出典とライセンスを付ける。裏面はもともと日本語のラベルがあるので、表のデザインの言語ルールとはぶつからない。
- **エンボス(etched)**: 第3弾の SEC と RSEC。参考は poke-holo(https://poke-holo.simey.me/、VStar / Trainer full art の etched foil)を Playwright で開き、CSS(GitHub の simeydotme/pokemon-cards-css)も読んだ。借りた手法は「凹凸のテクスチャを左右から照らした 2 枚を傾きでクロスフェード」「凹凸の稜線だけに虹を乗せる」。凹凸はウエハースの格子+星(`scripts/make-emboss.py`)。写真の窓には掛けず、枠だけ。
- **RSEC(リアルシークレット)**: コモンに紛れて出る(0.3、SEC の 1 未満)。開封も結果も普通のコモン。右下の角が少しめくれていて、そこからめくると下からレース仕様の写真のカードが出る。めくった記録は保存。番号は「046 / 045」のように枠の外の番号になっている(気づく人だけ気づく)。
  - めくりの参考: moooi「Paper Play」(Awwwards Site of the Day、紙の折り目の陰影)、Tear the Paper Ceiling(Honorable Mention、破れた紙のめくれ)、Shupatto(Site of the Day、たたむ動き)。いずれも作品ページと実サイトを Playwright で開いて撮影。
  - めくれた紙の裏は灰白のグラデーション+粒子、折り目側を暗く。
- **違和感演出**(スロットの「ハナビの遅れ」のような些細なもの): UR / SEC / RSEC のとき、ウエハースが**通常あり得ない 7 口目**を要求する(30%)、**裏返し**で断面が上にある(20%)。R でもまれに起きる(空振り)ので確定ではない。

## ラインナップ(伏せる)

C 15 / UC 12 / R 9 / UR 6 / SEC 3 + RSEC 3。写真は候補一覧から選び、`photo-check.py --fit` で切り取りを合わせた。
