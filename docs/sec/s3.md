# 第3弾(抹茶):ホモロゲ&レース

2026-10-15。テーマは作者が選んだ「ホモロゲ&レース」。市販のホモロゲーションモデルと、そのレース仕様・競技車。

## 新要素

- **抹茶ウエハース**: 第1弾と同じ写真(Paolo Neo、パブリックドメイン)から色を付け替え、緑のクリーム 1 層(`scripts/make-wafer.py`)。色は Commons の抹茶ウエハースの写真(CC0)を見て決めた。
- **スペック**: エンジン・出力・重量。英語版 Wikipedia の infobox から取得し(`scripts/fetch-specs.py`)、**その仕様の値かどうかを手で確かめた**ものだけ残した。車種全体の値やレース仕様と違う値は消した(不明ならなし)。カード裏面に載せ、出典(Wikipedia, CC BY-SA 4.0)も書く。
- **解説文**: 日本語版 Wikipedia の冒頭から 90 字以内(無ければ英語版)。カード裏面に引用として載せ、出典とライセンスを付ける。裏面はもともと日本語のラベルがあるので、表のデザインの言語ルールとはぶつからない。
- **ホロ(虹・グリッター・箔)**: 第3弾の SEC と RSEC。poke-holo(https://poke-holo.simey.me/)のシークレット・レインボーのホロを Playwright で見て、重ね方(虹のグラデーション+グリッター+ポインタの光、強いコントラストと彩度)を参考に、**画像を使わず CSS のグラデーションだけで**作った(`src/cards/rarity/holo.css`)。SEC 3-043・3-045 は虹、3-044 と RSEC は金。最初に作ったザラつき(凹凸画像)と生成テクスチャは作者の指摘で廃止。
- **RSEC(リアルシークレット)**: コモンに紛れて出る(0.3、SEC の 1 未満)。開封も結果も普通のコモン。右下の角が少しめくれていて、そこからめくると下からレース仕様の写真のカードが出る。めくった記録は保存。番号は「046 / 045」のように枠の外の番号になっている(気づく人だけ気づく)。
  - めくりの参考: moooi「Paper Play」(Awwwards Site of the Day、紙の折り目の陰影)、Tear the Paper Ceiling(Honorable Mention、破れた紙のめくれ)、Shupatto(Site of the Day、たたむ動き)。いずれも作品ページと実サイトを Playwright で開いて撮影。
  - めくれた紙の裏は灰白のグラデーション+粒子、折り目側を暗く。
- **違和感演出**(スロットの「ハナビの遅れ」のような些細なもの): UR / SEC / RSEC のときだけ、ウエハースが**通常あり得ない 7 口目**を要求する(30%)、**裏返し**で断面が上にある(20%)。R 以下では起きない(作者の指定)。

## ラインナップ(伏せる)

C 15 / UC 12 / R 9 / UR 6 / SEC 3 + RSEC 3。写真は候補一覧から選び、`photo-check.py --fit` で切り取りを合わせた。

## SEC(2026-10-15 作り直し)

最初は普段の枠にエンボスをかけただけで、アワード作品を見ていなかった(規則 0 違反)。3 枚とも、Awwwards で作品を探して実サイトまたは作品ページを Playwright で開いてから、専用デザインに作り直した。

| カード | 参考 | 借りた手法 |
|---|---|---|
| 3-043 | Paradigm Festival(Honorable Mention、実サイト) | 写真をオリーブ寄りのフィルム調に落とす。極端に横長の書体で 2 行、2 行目を右へずらす。小さな太字の日付行。四隅から入る光漏れ(色は車体のオレンジ) |
| 3-044 | ArkDes: Lewerentz Exhibition(Honorable Mention、実サイトは証明書エラーで開けず作品ページの画像) | 淡い青灰の地に写真を 1 枚のパネルで吊る。小さな「ROOM」ラベル+セリフの大文字の題、セリフの短い説明、部屋番号の列で現在の部屋に下線 |
| 3-045 | Design Bomb!!!(Honorable Mention、実サイト) | 黒地に極太イタリックの見出し(感嘆符付き)、角丸の蛍光ライムのパネル、色違いの帯に載せた単語を傾けて重ねたステッカー(日付) |

書体: Krona One、Libre Caslon Text、Archivo(いずれも OFL)。3-044 の説明文は Wikipedia の解説(1998 年のル・マン用に開発)だけを根拠にした。
